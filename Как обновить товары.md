# Как обновить товары на сайте «Протектор»

Инструкция для сотрудника склада. Весь ассортимент - это две таблицы:

- `data/tires.csv` - шины,
- `data/wheels.csv` - диски.

Одна строка = один комплект (или пара, или одна шина). Сайт собирается из этих таблиц автоматически.

## 1. Открыть таблицу

Открывайте файл в Excel или Google Таблицах. Разделитель - точка с запятой. Если Excel показал всё в одной колонке: «Данные» -> «Текст по столбцам» -> разделитель «точка с запятой».

Сохраняйте как **CSV UTF-8 (разделители - точка с запятой)**. Старый формат «CSV (разделители - запятые)» тоже прочитается, но русские буквы надёжнее в UTF-8.

Можно вести таблицу в Google Таблицах: «Файл» -> «Поделиться» -> «Опубликовать в интернете» -> лист -> CSV, ссылку вставить в `config.json` в поле `sheet_csv_url_tires` (или `sheet_csv_url_wheels`). Тогда сайт берёт данные прямо из Google Таблицы.

## 2. Колонки шин (`tires.csv`)

| Колонка | Что писать | Пример |
|---|---|---|
| артикул | уникальный номер, на сайте не меняется | Ш-1048 |
| статус | `в наличии`, `бронь` или `продано` | в наличии |
| сезон | `зима`, `лето` или `всесезон` | зима |
| шипы | для зимы: `да` - шипы, `нет` - липучка; для лета пусто | да |
| бренд | как на боковине | Nokian Tyres |
| модель | | Hakkapeliitta 10 |
| ширина / профиль / диаметр | три числа | 205 / 55 / 16 |
| индекс_нагрузки / индекс_скорости | | 94 / T |
| год | год выпуска | 2022 |
| dot | 4 цифры с боковины (неделя и год) | 1422 |
| кол_во | 1, 2 или 4 | 4 |
| протектор_мм | замер **по каждому колесу через /** | 8,6/8,5/8,4/8,5 |
| цена_комплект | цена за все колёса в строке, без пробелов | 28400 |
| грыжи_порезы | `нет` или что есть | нет |
| ремонты | `нет` или что было | 1 латка |
| выпавшие_шипы | число, только для шипов | 0 |
| состояние | можно оставить пустым - сайт посчитает по протектору (Отличное / Хорошее / Среднее) | |
| дата_поступления | 2026-10-15 или 15.10.2026 | 15.10.2026 |
| дата_продажи | заполняется при продаже | |
| примечание | видно покупателю как «Комментарий продавца» | хранились в тёплом гараже |

Цену за одну шину сайт считает сам (цена комплекта / количество).

| et | 47 |
| цо | 67,1 |
| кол_во | 4 |

| состояние | отличное / хорошее / среднее |
| дефекты | мелкие сколы на одном диске |

## 4. Фото

1. В папке `photos` создайте папку с артикулом: `photos/Ш-1048`.
2. Положите фото и назовите их по порядку с подписью:
   - `01 Комплект.jpg` - первое фото, оно идёт в каталог,
   - `02 Колесо 1.jpg`, `03 Колесо 2.jpg` ... - глубиномер в протекторе,
   - `06 DOT 1422.jpg` - дата выпуска на боковине.
   Подпись из имени файла показывается под миниатюрой. Номер в начале задаёт порядок.
3. Снимайте с телефона как есть: без фильтров, при обычном свете склада. Размер фото не важен, сайт сам уменьшит и ужмёт.

Что снимать обязательно: комплект целиком, глубиномер в протекторе каждого колеса, DOT. Если есть грыжа, латка или скол - отдельное фото крупно. Покупатель б/у шин смотрит именно на это.

## 5. Продажа и бронь

- Отложили комплект для клиента: статус `бронь`. На сайте появится плашка «В брони», кнопка брони пропадёт.
- Продали: статус `продано` и дата в `дата_продажи`. **Строку не удаляйте.**
  Сайт сам уберёт комплект из выдачи, покажет его в блоке «Недавно продано» и на его странице плашку «Продано» с похожими комплектами. Через 60 дней страница сама начнёт перенаправлять на страницу размера.
- Удалили строку по ошибке - не страшно: сайт помнит старые адреса (`data/published_urls.json`) и перенаправит на размер.

## 6. Пересобрать сайт

Один раз установить Python 3.10+ (python.org, галочка «Add to PATH»), затем `pip install pillow`.

Дальше после каждого изменения в папке сайта:

```
python build.py
```

В конце будет строка «Готово: ... страниц». Если ниже есть «Замечания по таблицам» - там написано, в какой строке ошибка (например, протектор записан не через «/» или нет цены). Строки с ошибками на сайт не попадают, остальное собирается.

Посмотреть сайт у себя до выкладки:

```
python build.py --serve
```

и открыть http://localhost:8080/protektor-demo/ .

Выложить: если сайт на GitHub, достаточно загрузить изменённые CSV и фото (через сайт GitHub или GitHub Desktop) - сборка и публикация запускаются автоматически, через 1-2 минуты сайт обновится. На обычном хостинге - залить содержимое папки `dist` по FTP.

## Частые ошибки

- «нет количества или цены» - в цене пробелы или знак ₽. Пишите только цифры: `28400`.
- «замеров протектора 3, а колёс 4» - количество замеров должно совпадать с количеством шин.
- «артикул повторяется» - у двух строк одинаковый артикул, исправьте один.
- «статус не понят» - пишите ровно `в наличии`, `бронь` или `продано`.
